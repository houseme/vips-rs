## API coverage

| Area | Safe API | Ownership and validation |
| --- | --- | --- |
| QOI | `qoiload_file`, `qoiload_buffer`, `write_qoi`, `write_qoi_buffer` | Buffer inputs retain their lifetime; encoded output uses native RAII storage |
| CICP | `cicp2scrgb`, `scrgb2cicp`, three public CICP enum types | Typed primaries/transfer; depth restricted to 8 or 16; full-range RGB matrix |
| Luminance | `percent_lum` | Finite percentile in 0–100 and histogram max in 1e-9–1e9; native code requires linear float RGB |
| Animation | `loop_count` | Native normalization of current and legacy GIF metadata |
| Metadata | `blob_value` | Returns a slice borrowing the image; validates null and slice length |
| Cropping | `smartcrop_at` | Explicit point of interest on a decoded image |
| Thumbnail | `thumbnail_file_at`, `thumbnail_buffer_at` | Encoded-source shrink-on-load; borrowed buffer lifetime retained |

The complete low-level additions include QOI source/target, region blending,
unlimited controls and draw primitives. Further safe wrappers require lifecycle,
prepared-region and aliasing contracts. In particular, native `copy_draw` may
reuse caller-owned memory. The existing detachment path protects Rust's immutable
borrowed buffers.

## Verified limitation

A valid QOI buffer saved by native RC1 fails in `vips_thumbnail_buffer` with
`qoiload_source: bad QOI magic`. A standalone C program reproduces the failure.
The source-header read/reopen path needs upstream rewind investigation. QOI file
and buffer load/save round trips pass. PNG-backed point-of-interest thumbnails
pass. Decode QOI explicitly before decoded-image geometry where needed.

The RC's HDR reference-white convention changes again in master PR #5295.
Revalidate HDR numerical fixtures before selecting a later native version.
[HDR change](https://github.com/libvips/libvips/pull/5295)

## Performance

`blob_value` returns the native metadata address directly. The regression test
checks pointer identity across repeated reads, and compile-fail coverage prevents
the slice from outliving its image. QOI encoding reuses `VipsOwnedBuffer`, avoiding
an extra Rust allocation and full-output copy. Specific-point thumbnail wrappers
call native encoded-source thumbnail operations to retain decoder shrink support.

The existing release-mode raw-export ABBA benchmark used a 2048×2048×3 image,
12,582,912 output bytes and 20 samples per mode. On native RC1, copied output had
a median of **835 µs**, native-owned output **645.833 µs**, ratio **0.773**.
A1/A2 drift was **0.6%**, passing the 10% gate. This measures about **22.7% lower
elapsed time** for the existing owned export path on this local workload.
A controlled native-version throughput comparison remains future work.

The final full-feature tests, Clippy, rustdoc and native 8.18 compatibility suite
were repeated using the fetched, pinned Git dependency.

- Full native RC1 tests pass, including four new API tests, existing image and
  UltraHDR tests, initialization tests, eight compile-fail cases, four run-pass

- `cargo clippy --all-targets --all-features --locked -- -D warnings` passes.
- A native old-version rejection check verifies the `v8_19` requirement.
- The RC build enables Highway, JPEG, PNG, TIFF, WebP, RAW, UltraHDR and lcms2.
  QOI is built in. Valid camera RAW files, APNG animation, JXL, HEIF/AVIF and
  native Windows execution remain additional validation work.

  separate pinned RC job so distro libraries can use their supported features.

## Improvement priorities

1. Resolve native QOI thumbnail source rewind and add multi-stage decode fixtures.
2. Add typed animation/loader/saver option structures, including APNG frame timing,
   failure policy, CICP/CLLI metadata and codec quality controls. Many current
   wrappers expose only positional arguments or a few options.
3. Benchmark actual decode→resize→encode workloads with fixed codec/SIMD settings,
   peak memory, latency percentiles and bounded worker counts. Recheck the native
   vertical-reduce changes separately from Rust buffer ownership.
4. Extend native Windows and codec-on/codec-off CI, and add per-target C/Rust ABI
   checks for callers using concrete low-level structures.
5. Consider safe streaming source/target wrappers once callback ownership,
   cancellation and error propagation are specified. These can reduce whole-file
   encoded buffering in long-running services.
